# 5가지 서비스 예시 (PHASE B 폴백)

사용자가 답을 못 하거나 부적절할 때 제시하는 **완성형 서비스 예시**다. 5개는 **표준이 서로 다르게**
나오도록 골랐다(제약 유무 × 자산 다중성 × 자금흐름). 각 항목은 Q1~Q5의 **시드**이며, 사용자가 고르면
PHASE C의 `field-guide.md`로 완결 문단까지 확장한다.

> 옵션으로 제시할 때: `label`=서비스 이름, `description`=한 줄 요약+예상 표준, `preview`=아래 Q시드 요약.
> 기본 추천(막혔을 때) = **A1**.

---

## A1 — 부동산 임대수익 조각투자  ·  표준 S4 (ERC-6909 + ERC-7943)  ★기본 추천

- **Q1**: 소액 투자자가 검증된 임대 부동산의 지분을 사고, 매월 임대수익을 자동 정산받는 조각투자 서비스.
- **Q2**: 연결 없이 물건·수익률·문서 탐색 → 지갑 연결 후 KYC 신청·승인 대기 → USDC로 청약(사전검증) →
  포트폴리오에서 보유 지분·월 임대수익 확인·수령 → 승인된 상대에게만 지분 이전.
- **Q3**: 임대 부동산을 물건별로 계속 상장(**동종 다수**). 보유 비율대로 월 임대수익을 pull-claim. 정산 MockUSDC.
- **Q4**: **KYC 통과 계정만** 보유·수신. 온체인엔 승인 결과만. 관할·적격·락업 제한 없음.
- **Q5**: 다크 미니멀 카드 그리드(수익률·잔여지분 배지), 청약 전 자격·한도·잔고 프리체크, 이전 시 canReceive 드라이런.
- **판정 근거**: 축1 제약 필요(KYC) + 축2 다중 대체가능 → **S4**. 부가 확장 없음(가스리스/거버넌스/풀운용 미언급).

## A2 — 미술품 원본 공동소유  ·  표준 S6 (ERC-721 + ERC-7943)

- **Q1**: 컬렉터들이 검증된 미술품 원본 1점의 공동소유권을 취득하고, 매각 시 지분대로 수익을 나누는 서비스.
- **Q2**: 작품·감정서·소장이력 열람 → 지갑 연결·적격 확인 → 공동소유 지분 청약 → 소유 증서·전시 현황 확인 →
  적격 상대에게만 소유권 이전, 최종 매각 시 정산 수령.
- **Q3**: **개별 고유 자산 1물1권**(작품 원본). 보유 기간 중 수익 없음, **매각 시 일시 분배**(pull-claim). 정산 MockUSDC.
- **Q4**: **적격투자자 + KYC**만 보유·이전. 온체인엔 판정 결과만.
- **Q5**: 작품 히어로 이미지 중심 상세, 감정서 문서 해시 대조 배지, 공동소유자 목록, 매각 정산 카드.
- **판정 근거**: 축1 제약 필요 + 축2 1물1권 → **S6**. (지분을 여러 작품으로 확장하려면 A1형 S4로 전환.)

## A3 — 매출채권 인보이스 파이낸싱  ·  표준 S4 (ERC-6909 + ERC-7943)

- **Q1**: 검증된 기업 매출채권을 조각으로 사서 만기에 원리금을 돌려받는 단기 수익 투자 서비스.
- **Q2**: 채권 목록·신용등급·만기·수익률 탐색 → 지갑 연결·적격 확인 → 조각 청약(사전검증) →
  포트폴리오에서 예상 상환일·수익률 확인 → 만기 상환금 수령, 조기 유동화 시 적격 상대에게 이전.
- **Q3**: 여러 매출채권을 계속 상장(**동종 다수**). **만기 일시 원리금 상환**을 pull-claim(부도 시 손실 가능 명시). 정산 MockUSDC.
- **Q4**: **적격투자자 한정 + KYC**. 관할 제한 옵션. 온체인엔 판정 결과만.
- **Q5**: 만기·수익률·리스크 등급을 강조한 리스트, 청약 전 잔여 물량·한도 프리체크, 만기 캘린더, 상환 상태 타임라인.
- **판정 근거**: 축1 제약 필요 + 축2 다중 → **S4**. 원금 손실 가능성을 UI·문서에 명시(보장성 표현 금지).

## A4 — 사모 운용 펀드 볼트  ·  표준 S2 (ERC-20 + ERC-7943) + ERC-4626

- **Q1**: 적격투자자가 USDC를 예치하면 운용사가 굴리고, 지분 토큰으로 손익이 반영되는 단일 운용 펀드 서비스.
- **Q2**: 전략·운용실적·수수료 열람 → 지갑 연결·적격 확인 → USDC 예치(지분 발행) →
  포트폴리오에서 지분 가치(NAV) 추이 확인 → 환매 청구로 지분 소각·정산 수령.
- **Q3**: **단일 펀드 1종**(대체가능 지분). 자금을 **풀에 모아 운용**, 손익이 지분 NAV에 반영. 정산 MockUSDC.
- **Q4**: **적격투자자 + KYC**만 예치·보유·이전. 온체인엔 판정 결과만.
- **Q5**: NAV·수수료·운용보고 중심 대시보드, 예치/환매 폼에 지분 환산 프리뷰, 지분가치 추이 차트.
- **판정 근거**: 축1 제약 필요 + 축2 단일 대체가능 → **S2**. 풀 운용 언급 → **ERC-4626 볼트 추가**(S1/S2 한정 허용).

## A5 — 탄소배출권 마켓  ·  표준 S3 (ERC-6909, 제약 없음)

- **Q1**: 누구나 검증된 탄소배출권(크레딧)을 조각으로 사고팔고, 상쇄에 사용하는 오픈 마켓.
- **Q2**: 프로젝트·인증기관·빈티지 탐색 → 지갑 연결 → USDC로 크레딧 구매 → 보유 크레딧 확인 →
  상쇄(retire)로 소각하거나 타인에게 자유 이전.
- **Q3**: 여러 크레딧 유형을 계속 상장(**동종 다수**). 수익 분배 없음, **가치는 시세·상쇄 효용**에서 발생. 정산 MockUSDC.
- **Q4**: **없음** — 누구나 자유 보유·이전. (→ 표준 ERC-6909, **ERC-7943 미적용**.)
- **Q5**: 프로젝트 카드(인증·빈티지·상쇄량 배지), 구매/상쇄 폼, 상쇄 증서 이력, 자유 전송 화면.
- **판정 근거**: 축1 제약 없음 + 축2 다중 → **S3**. 제약이 없으므로 ERC-7943을 붙이지 않는다(§5 축1).

## A6 (보너스) — 음원 로열티 조각투자  ·  표준 S4 (ERC-6909 + ERC-7943)

- **Q1**: 팬·투자자가 곡의 로열티 지분을 사서 스트리밍 수익을 분배받는 음악 조각투자 서비스.
- **Q2**: 곡·아티스트·과거 로열티 탐색 → 지갑 연결·KYC → 로열티 지분 청약 → 분기 로열티 수령 → 승인 상대에게 이전.
- **Q3**: 여러 곡을 계속 상장(**동종 다수**). 주기적 **스트리밍 로열티**를 pull-claim. 정산 MockUSDC.
- **Q4**: **KYC 통과 계정만** 보유·수신(권리 귀속 추적). 관할 옵션.
- **Q5**: 앨범아트 그리드, 곡 상세에 로열티 추이 차트, 분배 수령 카드, 이전 시 자격 드라이런.
- **판정 근거**: 축1 제약 필요 + 축2 다중 → **S4**. 정기 분배는 pull-claim.

## 표준 커버리지 요약 (예시 선택 시 다양성 확인용)

| 예시 | 축1 제약 | 축2 다중성 | 표준 | 부가 확장 | 자금 흐름 |
|---|---|---|---|---|---|
| A1 부동산 | 필요(KYC) | 다중 | **S4** | 없음 | 월 임대수익 분배 |
| A2 미술품 | 필요(적격) | 1물1권 | **S6** | 없음 | 매각 시 일시 분배 |
| A3 매출채권 | 필요(적격) | 다중 | **S4** | 없음 | 만기 원리금 상환 |
| A4 펀드볼트 | 필요(적격) | 단일 | **S2** | **ERC-4626** | 풀 운용·NAV·환매 |
| A5 탄소배출권 | **없음** | 다중 | **S3** | 없음 | 분배 없음(시세·상쇄) |
| A6 음원로열티 | 필요(KYC) | 다중 | **S4** | 없음 | 주기 로열티 분배 |

이 표는 사용자가 고른 예시가 어떤 표준·구현으로 이어질지 즉시 확인하는 용도이자,
5개를 제시할 때 **서로 다른 표준을 커버**하는지 점검하는 체크리스트다.
