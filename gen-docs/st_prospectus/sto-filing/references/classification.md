# 증권 유형 판정

근거: 자본시장법 §3~§4, §6⑤, §110 / 금융위 「조각투자 등 신종증권 사업 관련 가이드라인」(2022.4.28)
/ 「토큰증권 가이드라인」(2023.2.6) / 「신탁 수익증권 기초자산 가이드라인」(2023.12)

## 판단 원칙

**형식이 아니라 실질.** 상품명, 계약서 제목, 블록체인·NFT 채택 여부,
"공동구매"·"회원권"·"멤버십" 같은 표현은 판단 근거가 되지 않는다.

**묵시적 약정 포함.** 명시적 계약·약관·백서뿐 아니라 묵시적 합의, 스마트계약에 구현된
체결·집행 로직, 수익배분 구조, 광고 및 청약권유 문구까지 종합해 판단한다.
광고 문구가 수익 기대를 유발하면 계약서에 없어도 실질 판단에 반영된다.

**보충성.** 투자계약증권은 다른 증권 유형에 해당하지 않을 때 검토하는 보충적 지위다.
다른 유형을 **먼저 배제**한다.

**불확실하면 상향.** 두 유형 사이에서 갈리면 규제 강도가 높은 쪽을 기준으로 경고한다.

## STEP 0. 증권성 자체

자본시장법 §4① — 이익을 얻거나 손실을 회피할 목적으로 취득하는 권리로서,
투자자가 지급한 금전등 외에 **추가 지급의무를 부담하지 않는 것**.

- 취득 목적이 이익 획득 또는 손실 회피인가
- 추가 지급의무가 없는가
- 실물의 소비·이용이 주된 목적인 단순 매매나 회원권에 불과한가

증권 아님으로 판정되면 종료하되 반드시 경고한다:
수익 기대를 유발하는 광고·권유가 있으면 판단이 뒤집힐 수 있고,
증권 미해당을 전제로 한 모집은 무인가 영업 또는 유사수신에 해당할 위험이 있다.

## STEP 1. 다른 유형의 배제

| 유형 | 기준 |
|---|---|
| 채무증권 | 원금 반환 약정 또는 확정 이자 지급 의무가 있는가 |
| 지분증권 | 주식·출자지분 등 사원권적 지위인가 |
| 집합투자증권 | → STEP 2에서 별도 심사 |
| 수익증권 | 신탁의 수익권을 표시하는가 → STEP 3 |
| 파생결합증권 | 기초자산 가격에 연동해 사전에 정해진 방법으로 지급액이 결정되는가 |
| 증권예탁증권 | |

## STEP 2. 집합투자증권 배제 ★ 가장 사고가 잦은 지점

자본시장법 §6⑤ — 2인 이상의 투자자로부터 모은 금전등을 **투자자로부터 일상적인
운용지시를 받지 아니하면서** 재산적 가치가 있는 투자대상자산을 **취득·처분,
그 밖의 방법으로 운용**하고 그 결과를 투자자에게 배분하여 귀속시키는 것.

조각투자는 4요소 중 앞의 2개와 마지막 1개를 회피할 수 없다.
**"운용" 요소 하나만이 유일한 탈출구다.**

| 판정 | 결과 |
|---|---|
| 기초자산이 신고서 제출 시점에 **개별 특정**되고, 발행 후 자산 교체·추가·매각대금 재투자가 구조적으로 봉쇄됨 | 집합투자 아님 → STEP 3 또는 4로 진행 |
| 자산을 **묶어서(풀링) 모집**하고 사업자가 구성·비중·매매시점을 결정 | **집합투자 해당.** 인가 없이 발행 시 무인가 영업 |
| 매각 **시점** 결정권만 사업자에게 있음 | 회색지대. 처분 조건(최저가격 기준·최소보유기간·투자자 의결)이 계약으로 구속되는지에 따라 갈림. **반드시 경고 출력** |

현행 조각투자에서 풀링 발행이 금지되는 근거가 이것이다.
2026년 중 발표 예정인 하위법규에서 동일 종류 자산의 제한적 풀링 허용이 추진되고 있으나,
발표와 허용 범위를 확인하지 않은 상태에서 풀링 구조를 전제하지 않는다.

## STEP 3. 신탁수익증권 성립요건 — 전부 충족해야 함

| # | 요건 | 확인 |
|---|---|---|
| 3-1 | 기초자산이 신탁법상 재산권으로 이전 가능한가. 생물·소비재는 이전·관리의 법적 안정성을 별도 검토 |
| 3-2 | 위탁자–수탁자 간 신탁계약이 실재하는가 |
| 3-3 | **재산이 실제로 이전**되었는가. 명의만 넘기고 실질 지배가 위탁자에게 남으면 신탁 부인 위험 |
| 3-4 | 수탁자가 **자본시장법상 신탁업 인가**를 받은 자인가 |
| 3-5 | 신탁법 §22~§24에 따라 고유채권자의 강제집행이 배제되는가 |
| 3-6 | 비금전신탁 수익증권 발행에 대한 **혁신금융서비스 지정**을 받았는가 |
| 3-7 | 「신탁 수익증권 기초자산 가이드라인」상 위탁자 자기지분 보유 요건을 충족하는가 |

**3-4 또는 3-6 미충족 → 발행 불가.** 지정 절차 선행 또는 투자계약증권 구조로 재설계.

## STEP 4. 투자계약증권 성립요건 (Howey 4요소)

자본시장법 §4⑥ — 특정 투자자가 그 투자자와 타인 간의 **공동사업**에 금전등을 투자하고
**주로 타인이 수행한** 공동사업의 결과에 따른 **손익을 귀속**받는 계약상의 권리.

| # | 요소 | 확인 |
|---|---|---|
| 4-1 | 금전 또는 금전 환산 가능한 재산의 출연 |
| 4-2 | 손익을 공유하는 공동사업의 존재. 개별 투자자 손익이 사업 전체 성과에 연동 |
| 4-3 | 수익 창출이 사업자의 노력·전문성에 본질적으로 의존. 투자자 기여는 자금 출연에 그침 |
| 4-4 | 이익뿐 아니라 **손실**도 투자자에게 귀속. 원금 보장·최소수익 약정 부재 |

4요소를 전부 충족하고 STEP 1~3에서 다른 유형으로 확정되지 않으면 **투자계약증권**.

## STEP 5. 규제 경로

| | 투자계약증권 | 비금전신탁 수익증권 |
|---|---|---|
| 근거 | §4⑥ | §4⑤ + §110 + 혁신금융서비스 특례 |
| 사전 인허가 | 불요 | **지정 필수** |
| 신고서 제출의무자 | 사업자 본인 | 발행인 — 수탁자/위탁자 중 구조상 확정 필요 |
| 기초자산 귀속 | 발행인 명의 또는 투자자 공유지분 | 수탁자 명의 신탁재산 |
| 도산절연 | 구조적 보장 없음 → 별도 설계 필요 | 신탁법상 확보 |
| 투자자 권리 | 약관으로 창설되는 계약상 권리 | 신탁법상 법정 수익권 |
| 유통 | 현행 불가. 개정법 시행(2027.2.4) 후 투자매매·중개업자 통한 유통 가능 | 샌드박스 범위 내 플랫폼 유통 |
| 핵심 규범 | 「투자계약증권 투자자 보호 모범규준」('24.7) | 「신탁 수익증권 기초자산 가이드라인」('23.12) |
| 델타 파일 | `investment-contract.md` | `trust-beneficiary.md` |

## 출력

```
증권 해당 여부 :
증권 유형      :
확정 근거      : (조문 + 결정적 요소)
신뢰도         : 높음 / 중간 / 낮음
진행 가능 여부 : 진행 / 조건부 진행 / 중단(사유)
```

이어서 STEP 0~4 판정 로그, **재분류 위험 경고**, 필요 시 구조 재설계 권고,
법률의견서·비조치의견서가 필요한 쟁점을 출력한다.

재분류 위험 경고에는 최소한 다음을 포함한다:
집합투자 트리거(풀링·운용재량·자산교체), 신탁 부인(재산 이전 형해화),
채무증권 재분류(사실상 원금보장 약정, 손실보전 관행),
광고·권유 문구가 만들어내는 묵시적 약정.
