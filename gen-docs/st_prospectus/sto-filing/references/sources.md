# 1차 자료 · 참조 우선순위

뉴스 기사는 포함하지 않는다. 규제기관 원문과 공시 원문만 사용한다.
규범이 계속 개정되므로, 인용 전 최신 버전을 확인한다.

---

## 참조 우선순위 (Spec Discovery Rule)

**존재하지 않는 조문·서식·기재요령을 발명하지 않는다.**
이 스킬에 명시되지 않은 사항은 **아래 순서대로** 참조한다. 상위가 답하면 하위를 보지 않는다.

### 1순위 — 법령 원문 (로컬 코퍼스 우선)

색인이 있으면 웹보다 코퍼스를 먼저 본다. 응답이 빠르고 조문 인용에 `rel_path`가 붙는다.

```
make -C data-platform query Q="투자계약증권 집합투자 운용 배제"
make -C data-platform collections
```

코퍼스 `norms` 컬렉션에 자본시장법·시행령·시행규칙·금융투자업규정·금융혁신지원 특별법 등이 있다.
**없는 것** — 신탁법, 부동산투자회사법, 토양환경보전법, 석유 및 석유대체연료 사업법,
위험물안전관리법. 이것들은 https://law.go.kr 에서 확인하고, 확인하지 않았으면 그 사실을 알린다.

### 2순위 — 서식과 기재요령

금감원 「기업공시서식 작성기준」 붙임4·붙임5, 「투자위험요소 기재요령」, 정정요구 사례집.
**코퍼스에 없다.** 아래 §서식·§공시유의사항의 링크로 확인한다.

### 3순위 — **실제 제출된 신고서** ★ 반드시 본다

코퍼스 `sto` 컬렉션에 실물 6건이 있다. **절 구조·정형 문구·위험 소제목의 정본은
`reference-filings.md`이며, 그 근거가 이 실물들이다.**

```
make -C data-platform query Q="투자결정시 유의사항 투자계약증권"
make -C data-platform query Q="공유물 분할금지 특약 한계"
```

> **이 순위를 건너뛰면 무엇이 빠지는가.** 실제로 이 대조 없이 작성한 산출물에서
> **【투자결정시 유의사항】 전체, 정형 기타위험 6~8개, 공유물 분할금지 특약**이 통째로
> 누락됐다. 골격과 판정 논리가 맞아도 실물이 예외 없이 담는 것이 빠지면 정정요구를 받는다.
>
> PHASE 3 착수 전 **동종 자산 신고서를 최소 1건** 조회하고, 대조한 문서명을 심사검토서에 남긴다.

### 4순위 — 그 외

위에서 답을 찾지 못하면 **투자자에게 가장 불리한 해석**을 채택하고, 그 판단과 근거를
산출물 말미의 미확정 목록에 한 줄로 기록한다. 임의로 서식이나 기재요령을 만들지 않는다.

> 이 스킬의 심사 태도(§6 "선의로 읽지 않는다")와 같은 방향이다.
> 불확실할 때 발행인에게 유리한 쪽을 택하면 심사에서 뒤집힌다.

## DART에서 선례 신고서 찾기

**투자계약증권·신탁수익증권 전용 공시유형은 존재하지 않는다.**
DART 발행공시 하위 항목은 지분증권 / 채무증권 / 파생결합증권 / 합병등 / **기타** 5종뿐이고,
조각투자 증권은 전부 **`증권신고(기타)`**로 접수된다.

검색 폼이 JavaScript POST로 동작해 검색 조건이 URL에 실리지 않는다.
따라서 브라우저에서 직접 조작해야 한다.

1. https://dart.fss.or.kr/dsab001/main.do (회사별 검색)
2. 회사명 입력 — 열매컴퍼니 / 투게더아트 / 서울옥션블루 / 아티피오 / 스탁키퍼 / 데이터젠 /
   뮤직카우 / 루센트블록 등
3. 기간을 넓게 잡고 **최종보고서 체크 해제** (정정 이력 확인용)
4. 공시유형 → 발행공시 → `증권신고(기타)`
5. 결과 클릭 → 뷰어

**뷰어 URL 패턴** — 접수번호만 알면 로그인 없이 직접 열람 가능

```
https://dart.fss.or.kr/dsaf001/main.do?rcpNo={14자리 접수번호}
```

접수번호 = `YYYYMMDD` + 일련번호 6자리.

정정신고서를 정정 전후로 대비해 보는 것이 심사 지적사항 파악에 가장 효율적이다.

**진행 중 공모** — https://dart.fss.or.kr/dsac005/main.do (공모게시판, 유형별 탭)

**프로그래매틱 수집** — OpenDART 인증키 필요
- API 목록 https://opendart.fss.or.kr/intro/infoApiList.do
- 공시정보 활용마당 https://opendart.fss.or.kr/disclosureinfo/biz/main.do

정형 "증권신고서 주요정보" API는 지분·채무·파생결합·합병 위주로 제공되므로,
`기타` 유형은 공시목록 API로 받은 뒤 원문을 직접 파싱하는 편이 확실하다.

## 확인이 필요한 미확정 사항

작업 시점에 아래를 확인하고, 확인하지 않았다면 사용자에게 알린다.

1. **토큰증권 하위법규 개정안 및 조각투자 발행 모범규준** — 2026년 중 발표 예정.
   기초자산 적격성 기준, 풀링 허용 범위, 투자자 거래한도, 장외거래소 인가요건이
   여기서 확정된다. 확정 전에는 풀링 구조를 전제하지 않는다.
2. **개정 전자증권법·자본시장법 시행** — 2026.1.15 국회 통과, 2026.2.3 공포,
   전자증권법 2027.2.4 시행. 투자계약증권의 투자매매·중개업자 유통 허용이 핵심.
3. **「신탁 수익증권 기초자산 가이드라인」상 위탁자 보유의무의 정확한 요율과 예외** —
   원문에서 확인해 고정값으로 사용한다.
4. **「기업공시서식 작성기준」 최신 시행판** — 위 목록에서 확인.
