## 이 유형을 지배하는 전제

투자계약증권에는 신탁이 없다. 도산절연도, 법정 권리도 법이 주지 않는다.
따라서 신고서 전체가 **"법이 보장하지 않는 것을 계약과 내부통제로 창설했고,
그 한계를 투자자에게 알렸다"**를 입증하는 문서가 된다.

| 취약점 | 신고서에서 해야 할 일 |
|---|---|
| 도산절연 부재 | 발행인 도산 시 기초자산의 파산재단 편입 위험을 명시하고, 설계한 장치와 **그 한계**를 함께 기재 |
| 권리가 약관에 의존 | 투자자 권리를 약관 조항번호와 함께 특정하고, 약관 변경 절차·변경 제한도 기재 |
| 발행인이 곧 사업 운영자 | 매입·평가·보관·매각 4단계 각각에서 이해상충을 개별 서술. "없음" 처리는 그 자체가 지적 대상 |
| 유통 불가 | 중도 환금 불가를 명시. 개정법 시행 후 유통 가능성은 불확정 사항으로만 언급하고 **기대를 유발하지 않는다** |

## 제1부 II. 증권의 주요 권리내용 — 이 절 전체를 아래로 대체

1. **공동사업의 내용** — 목적, 참여자별 역할, 기간, 연장·조기종료 요건
2. **투자자가 취득하는 권리의 법적 성격**
   - 기초자산에 대한 공유지분권인지 채권적 청구권인지 명확히 특정
   - 공유지분인 경우 대항요건 구비 방법과 미구비 시 위험
3. **손익 배분 방법 및 산식** — 검산 가능한 수준으로
4. **기초자산 처분 의사결정 구조**
   - 의사결정 주체, 투자자 관여 범위, 처분 제약조건
   - 투자자가 처분 시점을 통제할 수 없다면 그 사실을 명시
5. **청산 및 정산 절차** — 시나리오별 정산표 3개 이상(기준/상승/하락),
   수수료·비용 반영, **손실 시나리오를 이익 시나리오와 동등한 비중으로**
6. **투자자의 권리** — 약관 조항번호와 함께 열거. 약관 변경 절차 포함
7. **양도·유통 제한 및 그 사유**
8. **발행인 도산 시 권리 보전 방법 및 한계**

## 추가 위험

**회사위험에 추가**
- **도산 위험 및 도산절연 부재** — 기초자산의 파산재단 편입 가능성,
  설계한 보호장치(공유지분 등기, 분리보관, 담보 설정)와 **그 법적 한계**
- **이해상충 위험 — 매입/평가/보관/매각 4단계를 각각 별도 소제목으로.**
  각 단계마다: 특수관계인 개입 여부 → 거래 상세 → 내부통제 절차 → 의사결정 방법
- 사업 지속성 위험 — 발행인이 사업을 중단하면 공동사업 수행 주체가 소멸함

**기타위험에 추가**
- 유통 제한 및 중도 환금 불가
- 제도 변경 위험 — 전자증권법·자본시장법 개정(2027.2.4 시행)이 유통·발행 구조에 미칠 영향.
  **유통 허용을 기대 요인으로 서술하지 않는다**

## 고유 심사 매트릭스

### X. 권리 구조
| X-1 | 공동사업의 내용이 §4⑥ 요건에 부합하게 기술되었는가 |
| X-2 | **권리의 법적 성격이 공유지분권인지 채권적 청구권인지 특정**되었는가 |
| X-3 | 공유지분인 경우 대항요건 구비 방법 및 미구비 시 위험 |
| X-4 | 처분 의사결정 주체와 투자자 관여 범위 |
| X-5 | 처분 제약조건이 계약으로 구속되는가 |
| X-6 | 투자자가 처분 시점을 통제하지 못한다면 그 사실이 위험으로 기재 |
| X-7 | 손익 배분 산식이 검산 가능한가 |
| X-8 | 청산 정산 시나리오 3개 이상, 수수료·비용 반영 |
| X-9 | **손실 시나리오가 이익 시나리오와 동등한 비중** |

### Y. 도산절연·내부통제
| Y-1 | **발행인 도산 시 기초자산의 파산재단 편입 위험**이 명시 |
| Y-2 | 보호장치가 구체적으로 기재 |
| Y-3 | **보호장치의 법적 한계**가 함께 기재 |
| Y-4 | 투자자 자금 분리관리 방식 |
| Y-5 | 기초자산 관리 전담 조직·인력의 실재 |
| Y-6 | 의사결정 기구와 의결 정족수 |
| Y-7 | 발행인 사업중단 시 기초자산 처리 절차와 실행 주체 |

### Z. 이해상충 — 4단계 각각 판정
| Z-1 | 매입 단계 |
| Z-2 | 평가 단계 |
| Z-3 | 보관 단계 |
| Z-4 | 매각 단계 |
| Z-5 | **"이해상충 없음"으로만 처리된 단계가 있는가** → 있으면 즉시 중대 이상 |

### W. 투자자 권리·유통
| W-1 | 장부열람권이 **약관 조항번호와 함께** 특정 |
| W-2 | 총회 소집권·의결권·정족수·의결사항 |
| W-3 | **약관 변경 절차와 변경 제한**이 기재 (권리가 약관에 의존하므로) |
| W-4 | 발행인 사업중단·파산 시 권리행사 방법 |
| W-5 | 발행인 자기취득분 비율·사유·보유기간·처분제한 |
| W-6 | 유통 불가·중도 환금 불가 명시 |
| W-7 | **개정법 시행 후 유통 가능성을 기대 요인으로 서술하지 않았는가** |
