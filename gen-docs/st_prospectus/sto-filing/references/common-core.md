# 공통 코어 — 두 유형이 공유하는 전부

작성(PHASE 3)과 심사(PHASE 4) 모두 이 파일을 먼저 읽고, 유형별 델타 파일을 덮어쓴다.

근거: 자본시장법 §119·§119⑤·§125, 시행령 §125, 증권의 발행 및 공시 등에 관한 규정 §2-3·§2-6,
금감원 「기업공시서식 작성기준」 및 별지서식(2026.6.30. 시행), 「투자위험요소 기재요령」('25.9),
「증권신고서 정정요구 사례집」(2023 / 2024~2025)

---

## 1. 작성 원칙

**추측 금지.** 입력에 없는 수치·일자·계약상대방·평가결과를 만들어내지 않는다.
미확정은 `[미확정: 확정 후 정정신고서 제출 예정]`으로 표기하고 말미에 모은다.

**전문가 확장 — 사실은 못 만들고, 함의는 전개한다.** 입력 항목은 세 성격으로 나뉘며,
성격에 따라 처리가 다르다. 확장은 **F의 함의를 N·J로 전개하는 것**이지 없는 F를
만드는 것이 아니다. 숫자·일자·상대방·평가결과는 어떤 경우에도 확장 대상이 아니다.

| 성격 | 무엇인가 | 처리 |
|---|---|---|
| **F 사실** | 재무수치, 취득가·취득일·취득처, 평가결과, 지정번호·지정기간, 청약일정, 모집총액·발행수량·단위가액, 계약상대방, 보험 부보금액, 과거 시계열 | 사용자가 준 값만 쓴다. 없으면 `[미확정]`. **지어내지 않는다** — 이것이 추측 금지의 대상 |
| **N 서술** | 위험요소 설명, 자산유형별 고유 위험, 이해상충 단계별 서술, 도산·신탁부인 위험 서술, 공시·적합성·분쟁처리 체계 | 사용자가 준 *사실을 근거로* 증권발행 전문가 수준으로 전개한다. 사실이 얇으면 서술도 얇게 두되, 근거 없는 정성 표현으로 부풀리지 않는다 |
| **J 판단** | 1인당 청약한도 설정 근거, 배정방식 산식, 손익·청산 시나리오표(사용자 가정 사용), 자금사용 세부 계획, 수수료 산정근거 서술부 | 규제 기준과 사용자 사실로 **초안을 제안**하되 반드시 `[발행사 확인 요망]`을 붙인다. 발행사가 확정할 값을 확정된 것처럼 쓰지 않는다 |

값 자체(한도 금액, 요율, 취득가 등)는 언제나 F다. J는 그 값에 붙는 **근거·산식·계획의
서술**에만 적용된다. 자산 종류가 F로 주어지면 §4의 해당 유형 위험 카탈로그를 N으로 전개한다.
정량 F는 §2.6 파라미터 시트로 분리 관리하며, 기획 모드에서는 가정치로 채우고 워터마크한다.

**보장·확정 표현 금지.** "수익 보장", "원금 손실 없음", "안정적", "확실한", "반드시".
예상 수익률은 산출 가정과 한계를 함께 제시할 때만 쓴다.

**불리한 사실 우선.** 위험을 구체적 수치와 함께 먼저 쓰고, 완화 요인을 뒤에 붙인다.
반대 순서는 그 자체로 정정요구 대상이다.

**한 소제목 = 한 위험.** 첫 문장에 위험의 결론을 요약하고 그 뒤에 근거를 전개한다.

**역참조 정확성.** `『제1부 - III. 투자위험요소 - 2. 회사위험 - 나.』` 형식으로,
실재하는 절만 가리킨다.

**작성기준일 = 증권신고서 제출일 전일.**

(`# N`, `# J`, `# 필수·판정`, `# 권장`). 성격 정의는 §1, 사용법은 §2.5(입력요청서) 참조.

- **[필수·판정]** — 값이 유형 판정을 바꿀 수 있어 PHASE 1에서 먼저 확인: 기초자산 개별

## 2.5 입력요청서 (Input Request Sheet)

PHASE 2a에서 산출한다. 공통 INPUT + 델타 INPUT을 통째로 던지지 않는다.
**판정된 유형과 기초자산 종류에 해당하는 필드만** 추려, 발행사가 오프라인에서
채워 되돌려줄 수 있는 채움표로 만든다. 각 항목에 우선순위·성격·미제공 시 영향을 표기한다.

형식:

| # | 항목 | 우선순위 | 성격 | 값(발행사 기입) | 미제공 시 영향 |
|---|---|---|---|---|---|
| 1 | 기초자산 취득가액·취득일·취득처 | 필수·작성 | F |  | 취득가–공모가 스프레드 설명 불가(치명) |
| 2 | 기초자산 개별 특정 정보 | 필수·판정 | F |  | 특정 불가 시 수리 거부·집합투자 재분류(치명) |
| 3 | 자체 평가 방법론·가정·한계 | 필수·작성 | N |  | 평가 재현성 미확보(중대) |
| 4 | 1인당 청약한도 설정 근거 | 필수·작성 | J | (한도값 기입) | 근거 초안 제안 예정, 발행사 확정 필요 |

- 파일로 저장: `입력요청서_<발행사>_YYYYMMDD.md`.
- 사용자는 **인라인 답변**과 **채운 시트 제출** 중 편한 쪽을 고른다. 둘 다 지원한다.
- 미응답 필수 F는 `[미확정]`으로 남기고 최종 산출물 말미의 미확정 목록에 모은다.
- PHASE 1에서 이미 받은 항목은 시트에서 제외하거나 확인만 표시한다(중복 질의 금지).

## 2.6 정량 파라미터 시트 & 시뮬레이션

재무·취득가·평가액·발행수량·청약일정·수수료율 등 **정량 F 항목**은 신고서 본문과 분리해
별도 시트로 관리한다. 신고서의 서술(N)·판단(J)은 이 시트의 값에서 파생되므로, 숫자를
바꾸면 관련 절이 다시 계산된다. **시트가 신고서의 계산 엔진이다.**

### 파일

`발행파라미터_<발행사>_YYYYMMDD.csv` — 엑셀에서 바로 열린다. 컬럼:

| 항목 | 성격 | 값 | 값출처 | 산정근거 | 단위 |
|---|---|---|---|---|---|

- **값출처**: `실측` / `가정`. 기획 모드의 가정치는 반드시 `가정`으로 표기한다.
- 라이브 수식 `.xlsx`가 필요하면 스크립트로 생성한다(값 변경 시 자동 재계산). 기본은 CSV.

### 시트가 산출하는 계산 — 심사에서 치명·중대로 걸리는 항목을 자동 충족

| 산출 | 산식 / 내용 | 대응 매트릭스 |
|---|---|---|
| 단위 모집가액 | (취득가 + 취득부대비용 ± 평가반영액 + 발행제비용) ÷ 발행수량 | 제1부 I.3 필수 산식 |
| 취득가→공모가 스프레드 분해 | 차액을 항목별 금액으로 | A-12 (미설명 시 치명) |
| 수수료의 순수익률 영향 | 투자자 부담 요율 → 세전·세후 순수익률 예시 | C-4 |
| 손익 시나리오 3종 | 기준/상승/하락, 수수료·비용 반영 | X-8 (투자계약형) |
| 분배금 산식 | 총수입 → 공제항목 → 순분배액 | S-2 (신탁형) |
| 청약일정 | T-14 ~ T+2 상대일자표 | B 계열 |

값출처가 `가정`인 산출물에는 `[가정치·시뮬레이션 — 제출용 아님]`을 붙인다.

### 모드 처리

- **제출 모드**: 미기입 F는 `[미확정]`. 계산은 확정치가 있는 부분만 수행한다.
- **기획 모드**: 가정치로 전부 채워 계산을 돌리되, 가정치·산출물 전부에 워터마크를 유지하고
  신고서 초안에 반영할 때도 워터마크와 `_시뮬` 파일명을 유지한다.

가정치가 워터마크 없이 신고서 본문에 사실처럼 기재되면 그 자체가 부실기재다.

## 3. 공통 문서 골격

### 표제부
제출처·제출일·회사명·대표자·소재지·연락처 / 증권의 종류·수·금액 / 모집방법

**공통 법정문구 3종** (유형별 추가 문구는 델타 파일 참조)
- 정부가 기재사항의 진실·정확을 인정하거나 증권의 가치를 보증·승인한 것이 아니라는 뜻
- "이 증권은 예금자보호법에 따라 보호되지 않습니다"
- "원금의 전부(100%)를 손실할 수 있으며, 손실은 전적으로 투자자에게 귀속됩니다"

### 【 대표이사 등의 확인 】 (법 §119⑤)

### 요약정보
1. 핵심투자위험 — 위험군별 3~5개, 1개당 3문장 이내
2. 모집 개요
3. 기초자산 요약 — 특정 정보·취득가·평가액·모집총액의 관계를 한 표로

### 제1부 모집 또는 매출에 관한 사항

**I. 모집 또는 매출에 관한 일반사항**
1. 공모개요
2. 공모방법 — 배정 원칙, 1인당 한도와 근거
3. 공모가격 결정방법
   → 필수 산식 전개: `기초자산 취득가 → 취득부대비용 → 평가 반영액 → 발행제비용
     → 모집총액 → ÷발행수량 = 단위당 가액`
   → 취득가와 모집총액의 차액을 **항목별 금액으로 분해**
4. 모집 또는 매출절차 — 청약·배정·납입·환불 일정표
5. 인수 등에 관한 사항 — 없으면 그 사실·사유·투자자가 부담하는 추가 위험
6. 청약증거금의 예치·보관·반환

**II. 증권의 주요 권리내용**
→ **유형별로 완전히 다르다. 델타 파일이 이 절 전체를 대체한다.**

**III. 투자위험요소** → 4절 참조

**IV. 인수인의 의견(분석기관의 평가의견)** — 없으면 그 사실과 사유

**V. 자금의 사용목적** — 조달·사용 계획표, 부대비용 세부, 집행·분리보관 방법

**VI. 그 밖에 투자자 보호를 위하여 필요한 사항**
- 기초자산 확인 방법 및 절차
- 정기·수시 공시 체계
- 투자자 적합성 확인
- 분쟁처리 절차

## 4. 공통 위험군

유형 고유 위험은 델타 파일에서 추가된다.

**1. 사업위험 — 기초자산에서 발생**
- 가격변동 위험 (과거 시계열·변동성 수치 필수)
- 환금성 위험 (자사 과거 처분 소요기간 실적)
- 기초자산 고유 위험 — 자산 종류별로 구체화
  - 미술품: 진위, 훼손, 도난, 작가 평판, 시장 유동성 편중
  - 가축: 질병·폐사, 사료가, 도체등급 편차, 경매가, 방역정책
  - 저작권: 정산 규정 변경, 이용량 감소, 권리분쟁, 존속기간 만료
  - 부동산: 공실, 임차인 신용, 갱신 실패, 수선비, 금리, 감정가 하락
- 평가의 불확실성 — 방법론의 전제와 한계, 평가액이 실제 처분가를 담보하지 않음
- 취득가 대비 공모가 프리미엄이 회수되지 않을 위험
- 시장·정책 변화

**2. 회사위험**
> 재무 부실·자본잠식·계속기업 불확실성이 있으면 **반드시 이 절 첫 항목**
- 재무 위험
- 사업 지속성 위험
- 내부통제 및 인력 위험
- 관계기관 의존 위험 (계좌관리기관·보관기관·평가기관)
- 과거 발행분 청산 실적이 부진하면 그 사실

**3. 기타위험**
- 청약·배정·납입 위험 — 배정방식, 미달 시 처리,
  **계좌관리기관의 역할이 원금·수익 보장과 무관함을 명시**
- 수수료 위험 — 투자자 부담분/사업자 부담분 분리 표, 항목별 산정근거, 수익률 영향 수치 예시
- 세무 위험
- 신고서 정정 가능성

## 6. 심사 태도와 출력 형식

### 태도
- **선의로 읽지 않는다.** 두 해석이 가능하면 투자자에게 불리한 쪽을 기준으로 판정.
- 누락과 부실기재를 동등하게 다룬다.
- "충분히"·"적절히"·"안정적으로" 같은 정성 표현에는 뒷받침 수치·절차·계약조항을 요구.
- 요약정보↔본문, 제1부↔제2부, 본문↔첨부 간 불일치를 교차 검증.
- 자기가 방금 쓴 문서라도 봐주지 않는다.

### 정정요구 카드

```
【지적 №___】  심각도: 치명 / 중대 / 보통 / 경미
────────────────────────────────────────
근거 규범 :  (조문 / 가이드라인 항목 / 부가조건 번호)
매트릭스  :  (A-12 등)
해당 위치 :  『제○부 - ○. ○○○ - 가.』
현행 기재 :  "(원문 인용 또는 '기재 없음')"
지적 사유 :  왜 투자자 보호에 미흡한가. 어떤 오해가 가능한가.
보완 요구 :  무엇을, 어느 수준까지, 어떤 근거자료로.
수정 예시 :  (그대로 반영 가능한 대체 문안)
```

### 심각도 — 공통 기준

| 등급 | 기준 |
|---|---|
| 치명 | 이 상태로 제출 시 수리 거부 또는 즉시 정정요구. 기초자산 특정 불가, 평가근거 부재, 취득가–공모가 스프레드 미설명, 보장성 표현, 법정문구 누락 |
| 중대 | 정정요구가 확실시됨. 수수료 산정근거 부재, 손익 시나리오 미제시, 투자자 권리 미부여, 재무 부실 은폐, 확인방법 부재 |
| 보통 | 심사 과정에서 보완 요구 예상. 정량 근거 부족, 서술 순서, 정합성 오류, 첨부 누락 |
| 경미 | 가독성·형식 |

유형별 추가 치명·중대 트리거는 델타 파일에 있다.

### 심사 결과 출력 순서

1. **심사 총평** (10줄 이내) — 수리 가능 여부, 핵심 결격 사유 3가지
2. **정정요구 사항** — 심각도 순 카드
3. **점검 매트릭스 판정표** — 전 항목 `충족 / 부분충족 / 미충족 / 해당없음` + 한 줄 코멘트
4. **효력발생 지연 리스크 추정** — 예상 정정 횟수와 근거
   > 제도 도입 초기 투자계약증권의 제출~효력발생 평균 소요기간은 약 66일이었고,
   > 그 주된 원인이 기초자산 관리·청약·배정 등 투자자 보호 항목의 부실 기재였다는 점이
   > 「투자계약증권 투자자 보호 모범규준」 제정 배경으로 제시된 바 있다.
5. **우선 보완 순서** — 치명 → 중대 순, 각 항목에 필요한 추가 확보 자료 명시
6. **잔여 확인 필요 사항** — 원문만으로 판단 불가하여 사실확인이 필요한 항목
