# 실물 신고서 대조 정본

실제로 금융감독원에 제출된 신고서에서 추출한 **절 구조·정형 문구·위험 카탈로그**다.
작성(PHASE 3)과 심사(PHASE 4)가 이 파일을 기준으로 누락을 점검한다.

> **왜 이 파일이 필요한가.** 골격과 판정 논리가 맞아도, 실물이 예외 없이 담는 정형 블록이
> 빠지면 정정요구를 받는다. 실제로 이 대조 없이 작성한 산출물에서
> **【투자결정시 유의사항】 전체, 정형 기타위험 6~8개, 공유물 분할금지 특약**이 통째로 누락됐다.

## 2. 실물 절 구조 (순서)

실물 신고서가 담는 절과 그 배열 순서다. **줄수·분량·비율은 싣지 않는다** — 문서 간
길이 비율도, 절별 분량도 강제하지 않기 때문이다(§ 아래 경고). 참조 대상은 "이 절이
존재하고 이 순서로 놓이는가"이지 "얼마나 긴가"가 아니다.

| 위치 | 절 |
|---|---|
| 표제부 직후 | **【 투자결정시 유의사항 】** |
| | 요약정보 (핵심투자위험·모집개요·기초자산) |
| | **정기공시 / 수시공시 / 자율공시** |
| 제1부 | I. 모집 또는 매출에 관한 일반사항 |
| 제1부 | **II. 증권의 주요 권리내용** |
| 제1부 | III. 투자위험요소 |
| 제1부 | IV. 인수인의 의견 |
| 제1부 | V. 자금의 사용목적 |
| 제1부 | VI. 그 밖에 투자자 보호를 위하여 필요한 사항 |
| 제2부 | I~X (발행인) |
| 제2부 | **XI. 상세표** |

**읽어야 할 두 가지.**

1. **II절에는 투자계약서 조문을 그대로 싣는다.** 실물은 투자자총회 소집·정족수,
   자료열람권, 기초자산 매각·사업손익 산정 단계, 중간정산까지 조문 단위로 전개한다.
   조항번호만 인용하고 조문을 싣지 않으면 투자자가 그 권리를 읽을 방법이 없다.

   > **분량·길이·비율은 심사 기준으로 쓰지 않는다.** 문서 간 길이 비율도, 절이 전체의
   > 몇 %인가도 판정 근거가 아니다. 판정 기준은 **"조문이 전개되었는가"**이지 "얼마나
   > 긴가"가 아니다. 실물마다 절 분량의 편차가 크고, 짧게 담은 신고서도 실제 제출·수리됐다.

2. **공시체계가 요약정보 뒤·제1부 앞에 독립 배치된다.** 투자자가 가장 먼저 확인해야 할
   정보 접근 경로이기 때문이다. 제1부 VI에 묻지 않는다.

## 4. 위험 카탈로그

### 4-1. 1층 — 정형 세트

> **측정 방법 (중요).** 아래 빈도는 **요약정보 핵심투자위험의 소제목(`가.`~`하.`)에
> 그 항목이 독립 항목으로 존재하는가**만 센 것이다.
> **문서 어딘가에 문언이 나오는 것과 다르다.** 예컨대 "투자설명서 교부"는 서울옥션블루
> 문서 전체에 23회 나오지만 **소제목으로는 없다.**
>
> **표본 n=3** — 스탁키퍼(소제목 28) · 투게더아트(38) · 서울옥션블루(39).
> 열매컴퍼니는 소제목 서식이 달라 자동 추출이 되지 않아 제외했다.
> **n=3에서 "정형"을 단정하지 않는다.** 아래 구분은 그 한계를 반영한 것이다.

**A. 필수 (3/3)** — 표본 전부에 소제목으로 존재. 누락 시 `중대`.

| 항목 | 배치 |
|---|---|
| 증권신고서 효력발생 의미 · 내용 변경가능성 | 기타위험 |
| 환금성 제약 관련 위험 | 기타위험 |
| 원금 미보장과 관련된 위험 | 기타위험 |
| 공모가 산정방식의 한계에 따른 위험 | 기타위험 |
| **미래예측진술의 포함으로 인한 위험** | 기타위험 |
| 일반청약자 배정방법에 따른 위험 | 기타위험 |
| 공모자금의 보관 방식과 사용내역 관련 위험 | 기타위험 |
| 이해상충 발생 및 특수관계자와의 거래 | 회사/기타 |

**B. 권장 (2/3)** — 표본 다수에 존재하나 보편적이지 않다. 누락 시 `보통`.
**본문에서 다루고 소제목만 없는 경우는 지적하지 않는다.**

| 항목 | 없는 표본 |
|---|---|
| 투자설명서 교부 관련 사항 | 서울옥션블루 |
| 투자자의 독자적 판단 요구 | 스탁키퍼 |
| 합산발행 · 패키지 발행 관련 사항 | 서울옥션블루 (해당 없으면 생략 가능) |
| 투자위험요소 기재내용 이외 위험 존재 | 스탁키퍼 |

**타 유형 적용.** `소유`(신탁형 투자설명서)와 뮤직카우에서 **효력발생·투자설명서 교부·
환금성·이해상충**의 문언이 확인된다. 나머지는 투자계약증권에서만 확인됐다.
신탁형 작성 시 실물 신탁 **증권신고서**로 재확인해야 한다(현재 코퍼스에 없음).

### 4-2. 2층 — 구조 고유 (유형별 델타에서 상세)

**투자계약증권** — 근거: 스탁키퍼·투게더아트·서울옥션블루

| 항목 | 3건 빈도 | 위험군 |
|---|---|---|
| **공유물 분할금지 특약의 한계 / 미승계** | 3/3 | 사업위험 |
| **투자계약 감시·감독 담당 외부기관 부재** | 3/3 | 회사위험 |
| **공동사업 운영자의 겸영으로 인한 위험** | 3/3 | 회사위험 |
| 공동사업자가 도산할 경우 투자자 위험 | 3/3 | 회사위험 |
| 공동사업구조 변경 또는 중단 위험 | 3/3 | 사업위험 |
| 공동사업 관련 법률 위배 등 소송·분쟁 | 3/3 | 사업위험 |
| IT시스템 결함 · 해킹 · 고객정보 유출 | 3/3 | 사업위험 |
| 기초자산 거래 및 증권 취득 관련 유동성 | 3/3 | 회사위험 |
| 핵심인력 유출 | 3/3 | 회사위험 |
| 일부 투자자의 반대 의사표시 · 공동사업 탈퇴 | 2/3 | 사업위험 |
| 공동사업자(참여자) 선정 관련 위험 | 2/3 | 회사위험 |

**공유물 분할금지 특약이 왜 반드시 필요한가 —**
공유지분 구조에서는 각 공유자가 언제든 공유물 분할을 청구할 수 있어 조각투자 구조 자체가
붕괴한다. 그래서 실물은 예외 없이 분할금지 특약을 두고 **동시에 그 한계를 위험으로 기재한다.**
실물이 기재하는 한계는 세 가지다.

- **존속기간 제한** — 스탁키퍼는 계약일로부터 3년으로 명시
- **해지 요건** — 투자자 전원 동의로 해지 가능하며, 해지는 공동사업 조기종료 동의로 간주
- **승계 문제** — 투게더아트는 소제목 자체가 `공유물 분할금지 특약의 **미승계** 관련 위험`

언급 빈도: 투게더아트 31 · 스탁키퍼 16 · 열매컴퍼니 16 · 서울옥션블루 13.

**신탁수익증권** — 실물 증권신고서 표본이 없다.
현행 `trust-beneficiary.md`의 카탈로그를 유지하고, 1층 세트만 추가한다.
**실물이 확보되면 이 절을 재작성해야 한다.**

### 4-3. 3층 — 자산 고유

**카탈로그는 `common-core.md` §4-3 하나뿐이다.** 여기 복제하지 않는다 — 두 벌이 되면 갈라진다.

이 파일이 더할 수 있는 것은 **각 자산에 실물 표본이 있는가**뿐이고, 그게 카탈로그의
신뢰도를 가른다. 표본이 없는 자산의 항목은 **실물에서 관찰한 것이 아니라 유추한 것**이다.

| 자산 | 실물 표본 | 카탈로그의 지위 |
|---|---|---|
| 미술품 | 3건 (투게더아트·서울옥션블루·열매컴퍼니) | 관찰됨 |
| 가축(한우) | 1건 (스탁키퍼) | 관찰됨 |
| 저작권 | 1건 (뮤직카우, **유형이 다름**) | 부분 관찰 |
| 부동산 | 1건 (`소유`, **투자설명서라 서식이 다름**) | 부분 관찰 |
| **주유소·에너지 설비** | **0건** | **유추** — 실물로 검증되지 않았다 |

> 표본 0건인 자산으로 작성할 때는 그 사실을 심사검토서(V-7)에 남긴다.
> 카탈로그가 비어서가 아니라 **검증되지 않아서** 위험하다.

## 5. 대조 절차

PHASE 3 착수 전과 PHASE 4에서 각각 수행한다.

1. **동종 자산 실물 1건 이상 조회.** 기초자산이 같은 것이 없으면 가장 가까운 것을 고른다.
   ```
   make -C data-platform query Q="투자계약증권 공유물 분할금지 특약"
   make -C data-platform query Q="투자결정시 유의사항 투자계약증권"
   ```
2. **절 구조 대조** — §2 표의 절이 **존재하는가**. 특히 유의사항 블록·공시체계 위치·상세표.
   **분량·길이·비율은 대조하지 않는다**(문서 간 길이 비율도, 절 분량도 강제하지 않는다).
3. **위험 카탈로그 대조** — §4-1 **A. 필수 8개**(누락 시 중대) + **B. 권장 4개**(누락 시 보통),
   §4-2 2층 해당 유형 전부.
4. **누락분은 작성하거나, 해당 없음 사유를 명시한다.** 조용히 빼지 않는다.
   단 **B 권장 항목을 본문에서 다루고 소제목만 없는 경우는 지적하지 않는다.**

## 6. 이 파일의 한계

- 빈도는 **투자계약증권 3건**의 **소제목** 기준이다. 열매컴퍼니는 소제목 표기가 달라
  자동 추출에서 제외했다. **n=3은 "정형"을 단정하기에 작다** — 그래서 3/3만 필수로 두고
  2/3은 권장으로 내렸다.
- **초판(2026-07-26)의 빈도표에 방법론 오류가 있었다.** 문서 전체 grep과 소제목 존재를
  혼동해 "투자설명서 교부 4/4"로 적었으나 소제목 기준으로는 2/3이다. 현재 표는 재측정본이다.
  같은 이유로 **분량 비율·유의사항 개수 같은 양적 값도 단일 표본에 불과**했고,
  표본 수치를 본문에서 걷어내고 심사 기준에서 제외했다(분량·길이·비율·개수는 강제하지 않는다).
- **신탁수익증권 실물 증권신고서가 코퍼스에 없다.** `소유`는 투자설명서이므로 서식이 다르다.
  신탁형 델타의 카탈로그는 이 대조로 검증되지 않았다.
- 「기업공시서식 작성기준」 별지서식 원문과 직접 대조하지 않았다. 실물이 그 서식을 따른다는
  전제하의 **간접 대조**다. 서식 원문은 `sources.md` 1순위로 확인한다.
- 「증권신고서 정정요구 사례집」과 대조하지 않았다. **빈도가 높다고 반드시 필수인 것은 아니다** —
  어떤 항목이 실제로 정정요구를 받았는지는 이 대조로 알 수 없다.
