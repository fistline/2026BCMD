## 출력 계약 (엄격히 따를 것)

산출물은 **전용 폴더**에 모은다. loose로 흩지 않는다.

```
gen-docs/st_prospectus/<slug>/
├── 증권신고서_<발행사>_<증권명>_초안_YYYYMMDD.md
├── 심사검토서_<발행사>_<증권명>_YYYYMMDD.md
├── 증권유형판정서_<발행사>_YYYYMMDD.md        (판정을 함께 수행한 경우)
├── 입력요청서_<발행사>_YYYYMMDD.md
└── 발행파라미터_<발행사>_YYYYMMDD.csv
```

`<slug>` — 발행사+증권명 기반 kebab-case ASCII. 한 번 정하면 고정한다.
**예약어**(슬러그 금지): `st-service-dapp`, `filing-to-dapp`, `sto-filing`.
이 슬러그는 dApp 브리지(`filing-to-dapp`)가 그대로 재사용해 `gen-apps/<slug>/`로 잇는다.

기획 모드 산출물은 파일명 끝에 `_시뮬`을 붙인다.

### A) 실물 대조 보고

대조한 문서명, 확인한 절 구조, 우리 산출물과 다른 점.

### B) 증권신고서 초안

표제부 → **【투자결정시 유의사항】** → 대표이사 확인 → 요약정보 → **공시체계** →
제1부(I~VI) → 제2부(I~XI) → 제3부 첨부 → 전문가 확인 → **미확정·가정치 목록**.

### C) 정량 파라미터 시트 (CSV)

컬럼: `항목, 성격, 값, 값출처(실측/가정), 산정근거, 단위`

### D) 심사검토서

1. **심사 총평** (10줄 이내) — 수리 가능 여부, 핵심 결격 사유 3가지
2. **정정요구 사항** — 심각도 순 카드
3. **점검 매트릭스 판정표** — 전 항목 `충족 / 부분충족 / 미충족 / 해당없음` + 한 줄 코멘트
4. **효력발생 지연 리스크 추정** — 예상 정정 횟수와 근거
5. **우선 보완 순서** — 치명 → 중대 순, 각 항목에 필요한 추가 확보 자료
6. **잔여 확인 필요 사항**

### E) 보고 요약

**치명·중대 지적사항의 개수와 그 내용을 먼저** 말한다.
"초안을 작성했습니다"로 시작하면 사용자가 심사 결과를 놓친다.

### F) 검증하지 않은 것

확인하지 않은 규범, 대조하지 못한 자료, 미확정으로 남긴 항목을 명시한다.
**검증하지 않은 항목을 통과로 표기하지 않는다.**

## 자기점검 (최종 출력 직전)

**실물 대조**

- [ ] 동종 자산 실물 1건 이상과 대조하고 문서명을 기록했다 — **또는 못 했다는 사실을 명시**했다 (V-7)
- [ ] **【투자결정시 유의사항】 블록이 표제부 직후에 있다** (V-1) ※ 개수는 기준 아님
- [ ] 유의사항 **№4 — 다른 증권 형태로 목적 달성 불가 판단 + 법률검토 의견**이 있다 (V-2)
- [ ] **1층 A. 필수 8개**가 전부 있다 (V-3). 해당 없음은 사유를 적었다
- [ ] 1층 B. 권장 4개를 확인했다 (V-3a) ※ 본문에서 다뤘으면 소제목 없어도 무방
- [ ] 공시체계가 요약정보 뒤 독립 절에 있다 (V-5)
- [ ] 제2부에 XI. 상세표가 있다 (V-6)
- [ ] 세무 위험을 기재했다 — 미확정이면 그 사실을 적었다 (V-10)

**사실과 추측**

- [ ] 지어낸 수치·일자·계약상대방·평가결과가 없다 (F는 준 값만)
- [ ] 기획 모드면 가정치 전부에 워터마크가 있고 파일명에 `_시뮬`이 붙었다
- [ ] J로 제안한 초안에 `[발행사 확인 요망]`이 붙었다
- [ ] 본문 수치가 파라미터 시트에서 전부 재현된다

**서술**

- [ ] **보장성 표현이 없다** — "수익 보장", "원금 손실 없음", "안정적", "확실한"
- [ ] 위험이 완화 요인보다 **앞에** 배치되었다
- [ ] 한 소제목 = 한 위험이고, 첫 문장이 결론 요약이다
- [ ] **손실 시나리오가 이익 시나리오와 동등한 비중**이다
- [ ] 역참조가 실재하는 절을 가리킨다

**정합성**

- [ ] 요약정보 ↔ 본문 ↔ 첨부서류가 일치한다
- [ ] 미확정 항목이 말미에 모여 있고 정정신고서 제출 예정이 표시되었다
- [ ] 심사를 **선의로 읽지 않고** 수행했다 (두 해석이 가능하면 투자자에게 불리한 쪽)
